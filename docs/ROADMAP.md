# خارطة الطريق

## التالي مباشرةً (يحتاج أصولًا منك)
- [ ] **التصدير المنظّم بالصور (PDF):** تخطيط مرن — صورتان نصف صفحة، ٥ صور شبكة، إلخ — مع بيانات الفعالية واسم المنفّذة والتاريخ والشعار. (يحتاج: الشعار في assets/logo)
- [ ] **تصدير Excel بقالب المديرية:** ملء نسخة من قالب «الشراكات» و«المبادرات» بأسماء الأشهر بالأحرف، وحساب «العدد» تلقائيًا. (يحتاج: ملف xlsx الرسمي)

## تحسينات مقترحة
- [ ] قراءة قائمة المنفّذين آليًا من ورقة Users بدل القائمة الثابتة في النموذج.
- [ ] مصادقة بـ PIN قصير لكل مستخدم (تعزيز بسيط للأمان).
- [ ] ترقيم/تحميل تدريجي للسجل عند تجاوز ~٥٠٠ سجل.
- [ ] رسوم بيانية للمؤشرات (Chart) بدل الأشرطة البسيطة.
- [ ] تنظيف الصور اليتيمة في Drive عند حذف صورة من فعالية.
- [ ] ورقة شراكات مستقلة بربع سنوي (Q1/Q2…) تُملأ من ربط الفعاليات بالشراكة.
- [ ] تصفية إضافية بالسجل (حسب النوع/المنفّذة) وبحث نصّي.
- [ ] نسخ احتياطي دوري لجدول البيانات.
